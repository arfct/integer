# CLAUDE.md

This repo follows the Artifact Primer: https://github.com/arfct/ops/tree/main/primer

## This repo

Integer Sans: Inter rendered to pixel grids, packed in one variable font in which every instance is a real bitmap. `vendor/inter/InterVariable.ttf` (OFL) is the source; `charset.txt` lists the codepoints. `scripts/import-inter.py` writes `glyphs/<grid>/{light,regular,bold}.txt` (grids 8 to 24): per grid it fixes x-height, cap, ascender, and descender rows from Inter's proportions, per weight it picks the Inter weight whose stem is a whole number of pixels, warps outlines onto those rows, and renders with FreeType's mono autohinter; the files are generated, so hand fixes go in `<weight>.overrides.txt` next to them, which the build applies on top. `scripts/build.py` turns runs of ink into rectangles, pads glyphs to a common rectangle count, and builds the font with stepped `opsz` (every exact size to 48, multiples as duplicate masters) and `wght` (200/400/800) axes, steep `avar` maps, and neighbour-bounded gvar tents so nothing interpolates. `scripts/check.py` renders every exact size through FreeType and fails on any gray pixel; run it after every build. `preview/index.html` is the specimen. Setup: `uv venv && uv pip install 'fonttools[woff]' pillow freetype-py`. Keep every size in whole pixels. `experiments/` holds earlier prototypes and the size and stepping tests. The font is OFL (a derivative of Inter); the code is MIT. Read `docs/design.md` before changing the model.
